# Experimental Agent Supervision Project
### Human supervision for AI agents in a desktop application
</div>

This is an author-led applied research project exploring secure, traceable and supervised orchestration of AI agents.

> The project is under active development. This public repository is a documentation and showcase space. It does not distribute source code or installers and does not claim production readiness.

## The idea

AI models can propose plans, code and automation. Turning those outputs into real actions requires context control, human approval, risk boundaries, traceability, validation and the ability to stop or roll back execution.

The project explores a supervision layer between people, models and execution tools.

## Demonstrated so far

- experimental Windows desktop application;
- supervised mission workflow;
- local mission persistence;
- experimental local-model execution through Ollama;
- automated engine and interface tests;
- validation of local processes and listening ports;
- installer workflow under independent validation.

## Not ready yet

- public distribution;
- production use;
- signed and independently validated installer;
- public cloud-provider integrations;
- broad autonomous code or command execution;
- complete independent security assessment;
- commercial availability.

## AI-assisted development

The project is led by Cristiano Silva and uses vibe coding with multiple AI tools for research, code generation, testing, documentation and diagnosis. Human responsibility remains central: AI-generated outputs require evidence, testing and review.
