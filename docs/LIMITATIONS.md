# Limitações conhecidas

- Protótipo em desenvolvimento ativo.
- Código-fonte ainda privado.
- Instalador ainda não distribuído ao público.
- Dependências externas podem ser necessárias nas builds de teste.
- Integração atual com modelo local não representa a visão multiagente completa.
- Nenhuma garantia de disponibilidade, desempenho ou adequação a uso específico.
- Nenhuma alegação de segurança absoluta.
- Mockups podem representar direção futura, não a interface vigente.
