# Política de segurança

## Escopo público
Este repositório contém somente documentação e materiais de apresentação. Não contém código operacional nem instaladores.

## O que pode ser relatado
Use o relato privado para comunicar exposição acidental de segredos, dados pessoais, caminhos locais, conteúdo confidencial ou outra falha de segurança relacionada aos materiais deste repositório.

## Relato responsável
Não publique vulnerabilidades, segredos, tokens, caminhos pessoais, dados de clientes, provas de conceito exploráveis ou informações que facilitem abuso em Issues ou Discussions.

Quando o recurso estiver habilitado, use **Security > Report a vulnerability** para enviar o relato de forma privada. Se esse botão não estiver disponível, abra uma Issue sem detalhes técnicos apenas para solicitar um canal privado.

## Sem recompensa prometida
O projeto não mantém programa de bug bounty e não promete pagamento, crédito público ou prazo de correção.

## Alegações
A existência desta política não representa certificação, auditoria independente ou garantia de segurança.
